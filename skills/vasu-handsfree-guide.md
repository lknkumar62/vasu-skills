# VASU Handsfree Guide (no automation)

Ye skill pure guide hai — isme executable phone steps nahi hain, bas VASU ye sab bata raha hai:

- Wake word: "Hey VASU" / "OK VASU" — kabhi bhi hands-free activate ke liye.
- Persona: "NOVA par switch karo" bolne se female voice NOVA aa jayegi; "sleep" bolo to standby.
- Sikhao Macro: VASU ko koi 2-3 step sequence sikha do (Settings me Sikho tab), phir trigger word se replay hota hai.
- Skill Store: GitHub se naye SKILL.md playbooks download ho jate hain (Settings > Skill Store > Refresh Skills).
- Screen automation: "screen numbers" on karke "click element 3" batao, ya "read screen" bolke current content sunwao.
- Safety: high-risk actions pe VASU bola confirmation maangta hai; Emergency Stop always available.

Chalao bolo aur enjoy karo.
